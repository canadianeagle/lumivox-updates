# LumiBox update channel

![LumiBox plugin interface](https://pub-6083e6c138814c7ab54752ad53b632a6.r2.dev/lumivox/main-3bb30f543093.png)

This repository is the public metadata channel for LumiBox Windows x64 releases. Truevined handles purchase and authenticated installer downloads.

When a signed update is ready, its GitHub release includes an Ed25519-signed update-windows-x64.json manifest. The manifest identifies the version, installer checksum, and signing certificate. Plugin source code and installer files live outside this repository.
